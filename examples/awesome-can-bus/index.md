# Awesome CAN bus

Curated tools and libraries for working with CAN bus. Generated from page frontmatter; do not edit by hand.

## Libraries

- [cantools](wiki/cantools.md) — Python package to parse CAN databases (such as DBC files) and encode or decode messages and signals.
- [python-can](wiki/python-can.md) — Python library for sending and receiving CAN messages across many interfaces, including SocketCAN.

## Topics

- [SocketCAN](wiki/socketcan.md) — Linux kernel CAN stack that exposes CAN interfaces as network devices used through the socket API.
